# HIV Dashboard Simulation (QA Automation Project)

## Project Overview
This is a full-stack QA automation simulation project.

It includes:
- Python ETL
- PostgreSQL database
- Node.js backend API
- HTML frontend
- Cypress API & UI automation tests

## Tech Stack
- Python
- PostgreSQL
- Node.js (Express)
- Cypress
- HTML/JavaScript

## Features
- ETL loads CSV data into PostgreSQL
- API exposes KPI endpoint
- Frontend fetches KPI and AI response
- Cypress validates:
  - API responses
  - UI behavior
